# Better Announcements & News System

## Goal
Create a consistent publishing system for official news, announcements, and community information.

## Features
- Announcement cards.
- Full announcement pages.
- Draft / Published / Archived states.
- Scheduled publishing.
- Categories and tags (tag normalisation follows 05-Event-Categories-and-Tags).
- Cover images.
- Author/staff attribution (roles/badges in 10 and 17).
- Published and updated dates.
- Pinned announcements.
- Related announcements.
- Optional Discord webhook posting (publishing flow in 23-Updates-Changelog-System).

## UX
The homepage should surface important announcements without overwhelming the user.

## Acceptance criteria
Staff can create, preview, publish, edit, archive, and feature announcements without editing code.
