# Website Search

## Goal
Provide one search experience across the major public content types.

## Searchable content
- Events (01-Better-Events-System)
- Announcements (06-Better-Announcements-News)
- Gallery submissions (08-Better-Gallery)
- Community profiles (16-User-Community-Profiles)
- FAQ/help articles (14-FAQ-Help-System)
- Updates/changelog (23-Updates-Changelog-System)

## Features
- Global search bar.
- Results grouped by type.
- Filters.
- Tags.
- Categories.
- Relevance sorting.
- Recent searches only if privacy-appropriate.

## UX
Search should have useful empty states and suggestions.

## Acceptance criteria
A user can search one term and discover relevant content without manually checking each section.
