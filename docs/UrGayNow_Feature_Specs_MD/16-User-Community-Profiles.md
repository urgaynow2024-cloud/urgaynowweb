# User & Community Profiles

## Goal
Give community members optional public profiles that connect their contributions together.

## Profile data
- Display name
- Avatar/profile image
- Bio
- Pronouns if voluntarily provided
- VRChat identity if voluntarily provided
- Social/community links
- Submitted gallery content (sourced from 07-Community-Submissions and 08-Better-Gallery)
- Hosted events (01-Better-Events-System)
- Badges (visual badges in 17-Staff-Badges-and-Roles)

## Privacy
Every optional field should have appropriate visibility controls. Do not expose private account information.

## Safety
- Block/report profile via the shared report system (see 11-Website-Report-System, 12-Report-Tracking).
- Staff moderation via the staff dashboard (see 10-Staff-Moderation-Dashboard).
- Sanitised links and safe image uploads (see 25-Implementation-Roadmap).

## Acceptance criteria
A visitor can understand a community member's public presence without gaining access to private account information.
