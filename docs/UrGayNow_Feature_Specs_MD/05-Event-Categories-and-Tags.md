# Event Categories & Tags

## Goal
Make events easier to discover and filter.

## Categories
Use a controlled category list, for example:
- Community
- VRChat
- Gaming
- Social
- Contest
- Creator
- Support
- Workshop
- Party
- Other

## Tags
Allow staff to add multiple tags such as:
- LGBTQ+
- Furry
- VRC
- Newcomers
- Adults
- Contest
- Music

## Requirements
- Category is required.
- Tags are optional.
- Tags should be normalised to avoid duplicates.
- Filtering must work on Events and Search.
- URLs should support shareable filters where practical.

## Acceptance criteria
Users can quickly narrow events by category, tag, date, and status.
