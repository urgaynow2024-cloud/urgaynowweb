# Staff & Moderation Dashboard

## Goal
Provide staff with one clear place to manage reports, submissions, events, announcements, and moderation actions.

## Dashboard areas
- Reports
- Community submissions
- Events
- Announcements
- Polls
- Users
- Audit log
- Moderation statistics

## Report statuses
Use the canonical report-status taxonomy defined in 12-Report-Tracking (Received, Under Review, Action Taken, Resolved, Dismissed).

## Permissions
Use granular role permissions rather than relying only on a generic admin check.

Suggested roles:
- Founder
- Admin
- Moderator
- Event Manager
- Community Manager

## Audit log
Record:
- Staff member
- Action
- Target
- Timestamp
- Previous value where relevant
- New value where relevant

## Acceptance criteria
Staff can understand what needs attention without navigating multiple unrelated admin pages.
