# Anonymous Reporting

## Goal
Allow anonymous reports when revealing the reporter's identity could create unnecessary risk.

## Behaviour
- Anonymous reporting should be available as a toggle on the report form for appropriate categories (see 11-Website-Report-System).
- Do not display reporter identity in ordinary moderation views when anonymous mode is selected.
- Staff should still receive the information necessary to investigate the report.
- Explain that anonymous does not necessarily mean technically untraceable if server/security logs are retained.

## UX
Use a clear explanation beside the anonymous option.

## Acceptance criteria
The interface never accidentally reveals an anonymous reporter's submitted contact information to ordinary moderators.
