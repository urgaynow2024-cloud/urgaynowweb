# Shared Design System & UX Overhaul

## Goal
Make Ur Gay Now feel like one polished platform rather than a collection of individually designed pages.

## Visual direction
Create a consistent modern LGBTQ+ community aesthetic with:
- Strong typography hierarchy.
- Modern cards.
- Consistent spacing.
- Clear buttons.
- Subtle depth.
- Better empty states.
- Consistent icons.
- Responsive layouts.
- Purposeful use of gradients/accents without reducing readability.

## Components
Create reusable components for:
- Cards
- Status badges
- Tabs
- Filters
- Search
- Modals
- Forms
- Toasts
- Empty states
- Loading states
- Error states
- Pagination/infinite loading
- Confirm dialogs

## UX principles
- Make the primary action obvious.
- Reduce unnecessary page-to-page navigation.
- Keep related information together.
- Give every action feedback.
- Use consistent terminology.
- Avoid excessive animations.
- Design mobile and desktop together.

## Homepage
The What's Happening? homepage is defined in 20-Whats-Happening-Homepage; this design system supplies the shared components (cards, status badges, tabs/filters, search, modals, forms) reused across it and all other public surfaces.

## Acceptance criteria
The same components and interaction patterns should be reused across Events, Reports, Gallery, Announcements, Profiles, Updates, and Help.
