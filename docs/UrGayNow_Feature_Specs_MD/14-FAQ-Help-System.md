# FAQ & Help System

## Goal
Create a searchable help centre so common questions can be answered without contacting staff.

## Features
- FAQ categories.
- Search (global search experience in 15-Website-Search).
- Expandable answers.
- Dedicated article pages.
- Related articles.
- Contact/report escalation (see 11-Website-Report-System).
- Last updated date.
- Staff-managed content.

## Suggested categories
- Getting Started
- VRChat
- Events
- Community
- Reports
- Accounts
- Safety
- Website
- Accessibility

## Acceptance criteria
Users can find relevant help quickly and every article has a clear path to report an issue if the answer is insufficient.
